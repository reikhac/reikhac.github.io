Objectives & Outcomes

Target competencies and educational goals established for this course.

Course Objective

This course aims at providing the fundamentals of algorithm design and analysis and explains the concepts of the greedy method and dynamic programming. It also illustrates the methods of backtracking and branch-and-bound techniques to solve computational problems.

CO1

Describe fundamental concepts of algorithms for solving computational problems.

CO2

Analyze various algorithmic approaches and dynamic programming to understand their efficiency and applicability.

CO3

Evaluate algorithms based on time and space complexity to determine effectiveness for different problem scenarios.

CO4

Design appropriate design paradigms and optimization techniques to solve real-world computational problems.

CO5

Develop the ability to apply advanced algorithmic techniques through continuous self-learning.

Syllabus & Learning Modules

Unit-wise breakdown of foundational and advanced algorithm concepts.

  • Performance analysis: space complexity, time complexity.
  • Asymptotic notation: Big O, Omega, Theta, and little-o notation.
  • Recurrence relations and methods of analyzing recurrences.
  • Probabilistic analysis.
  • Practice: Determine time/space complexity for loops, conditionals, and given logic.
Suggested Activity: Assignment on time/space complexity calculation for given code logic.
  • Divide-and-conquer design paradigm & core concepts.
  • Merge sort and its formal recurrence analysis.
  • Long integer multiplication.
  • Strassen’s matrix multiplication.
  • Master method for solving recurrence equations.
  • Job Sequencing Problem with Deadlines.
Suggested Activity: Flipped-classroom puzzle session and review of relevant GATE questions.
  • Greedy choice properties & optimal substructure.
  • Activity Selection Problem, Huffman Codes, and Fractional Knapsack.
  • Dynamic Programming formulation and state-transition recurrence relations.
  • 0–1 Knapsack and Matrix Chain Multiplication.
  • Optimal Binary Search Tree (OBST) and Longest Common Subsequence (LCS).
  • Space-optimization techniques in multi-stage graphs.
Suggested Activity: Project-based experiential learning via treasure-hunt problem solving; state-transition quiz.
  • Multithreaded algorithm architectures and parallel models.
  • Polynomial multiplication and Fast Fourier Transform (FFT).
  • Extended Euclid Algorithm (gcd and Bézout coefficients).
  • Naïve string matching and Rabin–Karp algorithm (rolling hashes).
  • Computational geometry & Convex Hull: Graham’s Scan and Jarvis March.
Suggested Activity: Implementation assignment on Rabin–Karp string search; quiz on Euclid & FFT algorithms.
  • Complexity classes: P, NP, NP-Hard, and NP-Complete.
  • Classic NP-Complete problems: Vertex-Cover, TSP, Set-Covering, Subset-Sum.
  • Backtracking & Branch-and-Bound: N-Queen Problem, Graph Coloring, Hamiltonian Cycle.
  • Assignment Problem, Knapsack Problem variations.
  • Introduction to Approximation and Randomized Algorithms.
Suggested Activity: Case assignment on approximation heuristics and analysis of GATE tractability questions.
  • Flow networks, source-sink formulations, and residual networks.
  • Maximum Flow: Ford–Fulkerson method and Edmonds–Karp algorithm.
  • Push–Relabel and Relabel-to-Front algorithms.
  • Minimum-Cost Flows and Cycle-Cancelling algorithm.
Suggested Activity: Flipped classroom on Push-Relabel mechanics; review of GATE network flow problems.
